📻 Quansheng UV-K5 / UV-K6 Türkçe Firmware

Egzumer tabanlı, optimize edilmiş ve tamamen Türkçeleştirilmiş açık kaynaklı firmware arayüzü.

Yükleme Adımları:
  1. Öncelikle aşağıdaki "📦 .bin İndir" butonuna tıklayarak en güncel firmware.packed.bin dosyasını bilgisayarınıza indirin.
  2. Telsizi kapatın.
  3. PTT mandalına basılı tutarak telsizi açın (Üstteki fener LED'i sabit yanacak, ekran karanlık kalacaktır).
  4. Programlama kablosunu telsize (iyice bastırarak) ve bilgisayara takın.
  5. "🚀 Web Flasher'ı Aç" butonuna tıklayın, açılan sayfada "Select Firmware" diyerek indirdiğiniz .bin dosyasını seçip yüklemeyi başlatın.
